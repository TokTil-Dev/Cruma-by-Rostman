---
title: Scene file
kind: term
summary: A file of the video director that holds one scene, named like flight_2.scene.json.
related: scenes/video-director, start/where-cruma-writes
---
**Save** writes it into `Documents/Cruma/Scenes`, the folder of `viewer.director.scenes_folder` in `cruma.conf`. It
holds numbers and the names of what the client has, and no part of the client, so it can go to another person. A video,
a Blender export and a client file can be made from it again. See [Where Cruma writes](guide:start/where-cruma-writes).
