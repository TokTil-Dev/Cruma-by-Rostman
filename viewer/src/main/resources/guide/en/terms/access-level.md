---
title: Access level
kind: term
summary: How far an AI agent may go in Cruma: See, Edit or Write, each holding the one before it.
related: agent/access-and-stop
---
See only looks, reads and exports. Edit also changes the world in memory, where Undo takes it back. Write also saves
into the client and the server folders. Cruma checks the level on each call. See [Access and
Stop](guide:agent/access-and-stop).
