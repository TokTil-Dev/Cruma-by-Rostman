---
title: MCP
kind: term
summary: The Model Context Protocol: a common way for an AI program to use the tools of another program.
related: agent/what-agents-do, agent/connect-an-agent
---
Cruma speaks it through `Cruma mcp`, which the agent's program starts by itself. The agent then sees a list of tools,
such as one that takes a picture or one that exports a location. See [What an AI agent can
do](guide:agent/what-agents-do).
