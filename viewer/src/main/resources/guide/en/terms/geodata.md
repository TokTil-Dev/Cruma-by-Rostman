---
title: Geodata
kind: term
summary: The server's map of floors and walls: for each 16-unit cell, its heights and which sides are open.
related: geodata/what-is-geodata
---
The server has no meshes and no terrain, so it uses geodata to decide where characters can stand and walk. It is made
from the maps of the client and kept in one file for each [region](guide:terms/region). Read
[What is geodata](guide:geodata/what-is-geodata).
