---
title: Package
kind: term
summary: One file of the client that holds many things of one kind, such as textures, meshes or sounds.
related: start/how-a-map-is-built
---
A map is a package too, `.unr` in `Maps`. Textures are in `.utx`, static meshes in `.usx`, animations in `.ukx`, sounds
in `.uax` and scripts in `.u`. A map names the things it uses, and the client finds them in the package of that name.
See [How a map is built](guide:start/how-a-map-is-built).
